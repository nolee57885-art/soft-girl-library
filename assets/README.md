# Little Library artwork

Add the two reference images to this folder using these exact filenames:

- `library-background.webp` — the blossom-tree circular library scene (first reference image)
- `bookshelf-wall.webp` — the close-up bookcase scene (second reference image)

The app already references these paths. The currently-reading shelf is also rendered as clickable book spines using each book's saved title; selecting a spine opens that book for editing.

You can upload the images here with GitHub's **Add file → Upload files** button. Convert the images to WebP first, or use the same filenames with `.jpg` and update the two image paths in `index.html` accordingly.
